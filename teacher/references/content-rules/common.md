# 공통 내용 규칙

이 문서는 HWPX, XLSX, HTML 등 산출물 형식 workflow 위에 얹는 교사 업무문서 공통 내용 규칙이다.

## 자료 참조

- 사용자 요청의 명시 지시를 최우선으로 따른다.
- 정리된 `docs/*.md`를 원본 파일보다 먼저 본다.
- Markdown 자료로 충분하지 않을 때만 현재 작업과 직접 관련된 원본 증빙 파일을 연다.
- 개인정보, 서명, 신분증, 통장사본, 재직증명서는 필요한 제출물에만 사용한다.
- 제출용 파일에는 불필요한 임시 파일, 분석 결과, 개인 메모를 포함하지 않는다.

## 표기

- 학교명은 정식 명칭을 기본으로 쓴다.
- 표 폭이 좁은 경우에만 약칭을 사용한다.
- 날짜는 양식 형식을 따른다. 예: `2026.03.01`, `2026.03~현재`, `26.03~현재`
- 연수, 경력, 실적은 양식 열 구조에 맞게 기간, 기관, 역할, 시간을 압축한다.

## 작성 품질

- 양식 폭에 맞지 않는 긴 내용은 글자 크기를 무리하게 줄이기보다 핵심만 요약한다.
- 수식어보다 객관적 역할, 기간, 결과, 산출물을 우선한다.
- 같은 활동이 여러 문서에 반복될 때는 문서 목적에 맞게 강조점을 바꾼다.
- 모든 수정본, 완성본, 제출용 파일은 작업폴더 안의 `완성본/` 폴더에 저장한다.
- 원본 파일은 덮어쓰지 않는다.
- 결과물은 가능하면 다시 열거나 렌더링해서 내용 유지와 잘림 여부를 확인한다.
