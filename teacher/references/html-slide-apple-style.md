# HTML 슬라이드 Apple 스타일

Apple 스타일은 사진/오브젝트 중심의 절제된 발표자료를 만들 때 사용한다. 공통 발표자료 원칙은 `references/html-slides.md`를 우선하고, 이 문서는 Apple식 시각 언어만 정의한다.

## 핵심 방향

- UI가 아니라 오브젝트가 주인공이 되게 한다.
- 슬라이드는 흰색, 파치먼트, 다크 타일을 번갈아 쓰는 전체 화면 섹션으로 구성한다.
- 장식적 그래디언트, 불필요한 그림자, 과한 테두리를 쓰지 않는다.
- 큰 제목, 짧은 보조 문장, 중앙 오브젝트 하나를 기본 단위로 삼는다.
- 설명을 늘리는 대신 한 장면이 바로 이해되게 만든다.

## 색

- 텍스트, 아이콘, 선, 강조 요소의 색은 최대 3가지로 제한한다: 검정, 파랑, 주황.
- 흰색 배경, 검정 배경, 파치먼트 배경처럼 화면의 기본 배경색은 색 개수 제한에서 제외한다.
- 검정 배경의 흰색 본문은 역상 표현으로 보고, 새 강조색으로 세지 않는다.
- 회색 텍스트를 별도 색처럼 쓰지 않는다. 보조 텍스트와 구분선은 검정 또는 흰색의 투명도로만 처리한다.
- 기본 조합은 검정과 파랑 2가지다.
- 검정은 본문, 구조, 상단 바, 기본 텍스트에 쓴다.
- 파랑은 Codex, 도구 실행, 파일 처리, 선택 상태, CTA에 쓴다.
- 주황은 문제 상황, 전환점, 대비가 필요한 핵심 단어처럼 예외적으로만 쓴다.
- 다크 배경에서는 파랑과 주황을 약간 밝게 조정해 대비를 확보한다.
- 한 슬라이드에서 주황을 쓰면 다른 강조를 줄여 주황이 한 번만 눈에 들어오게 한다.

## 타이포그래피

- 제목은 SF Pro Display 계열 또는 시스템 display 스택을 우선한다.
- 한글 환경에서는 `Apple SD Gothic Neo`, `Pretendard`, `system-ui` 순으로 대체한다.
- 제목은 600 weight를 기본으로 하고, 너무 굵은 700 이상은 피한다.
- 제목은 의미 단위로 직접 줄바꿈한다.
- 본문은 제목보다 충분히 작게 두어 위계를 분명히 한다.

## 레이아웃

- 1920x1080 데스크톱 발표 화면을 기준으로 좌우를 넓게 쓴다.
- 콘텐츠가 좁게 중앙에 모이지 않도록 최대 폭을 1700px 이상까지 열어둔다.
- 기본 배치는 시각적 중앙 정렬이다. 일부러 하단에 무게를 둘 때는 제품/오브젝트가 무대 위에 놓이는 느낌이 나야 한다.
- 전체 화면 타일은 모서리를 둥글게 하지 않는다.
- 카드나 파일 오브젝트는 필요할 때만 쓰고, 오브젝트 자체의 그림자만 허용한다.
- 제작 조건을 보여주는 배지나 pill은 청중에게 의미가 있을 때만 쓴다. `HTML 발표자료`, `1920x1080`처럼 내부 제작 기준에 가까운 표기는 표지에서 빼는 편이 낫다.

## 오브젝트 표현

- 실제 제품 사진 대신 발표 주제의 핵심 오브젝트를 만든다.
- 교사 업무문서 발표에서는 HWPX, XLSX, HTML, 폴더 구조, 양식 미리보기 같은 오브젝트를 크게 배치한다.
- 오브젝트에는 단일 soft shadow를 쓸 수 있지만, 카드/버튼/텍스트에는 그림자를 주지 않는다.
- 이미지 생성은 표지나 핵심 전환 장면처럼 이미지가 메시지를 즉시 강화할 때만 사용한다.
- 생성 이미지가 장식처럼 보이거나 설명을 더 흐리게 만들면 CSS 오브젝트로 처리한다.
- 이미지 후보가 있다면 먼저 `왜 이 이미지가 필요한지`, `텍스트보다 무엇을 더 잘 보여주는지`를 판단한다.
- 교사용 업무문서 발표에서는 현실적인 책상 사진보다 파일, 폴더, 양식, 작업 흐름을 상징하는 깨끗한 오브젝트가 더 잘 맞는 경우가 많다.

## 버튼과 컨트롤

- CTA는 파란색 pill 버튼을 사용한다.
- 보조 버튼은 파란색 테두리 pill로 표현한다.
- 발표 컨트롤은 작고 조용하게 두며, 슬라이드 내용보다 눈에 띄지 않게 한다.

## 애니메이션

- Apple 스타일에서는 움직임을 적게 쓰되, 오브젝트가 무대 위에 놓이는 느낌을 준다.
- 제목은 짧게 fade-up, 오브젝트는 약한 scale-up 또는 slide-up을 사용한다.
- 여러 요소를 움직일 때는 80-140ms 간격으로 순차 진입시킨다.
- 움직임 시간은 420-700ms 안에서 끝낸다.
- easing은 `cubic-bezier(.2, .8, .2, 1)` 계열의 부드러운 감속을 사용한다.
- 반복 pulse, bounce, 회전 같은 장난스러운 모션은 쓰지 않는다.

## 금지

- 검정, 주황, 파랑 외의 새 강조색 추가
- 장식용 그래디언트 배경
- 카드나 텍스트 그림자
- 과도한 아이콘 장식
- 의미 없는 둥근 카드 남발
