# 개인 프로필 자료 구조

배포용 스킬에는 실제 개인정보를 넣지 않는다. 사용 프로젝트마다 `docs/` 아래에 개인 자료를 둔다.

## 권장 파일

- `docs/프로필.md`: 기본 인적사항
- `docs/이력서.md`: 학력, 경력, 강의/업무 실적
- `docs/연수이수목록.md`: 연수 과정명, 기관, 기간, 시간, 이수번호
- `docs/근무경력.md`: 학교별 근무 기간과 담당 업무
- `design.md`: HTML 발표자료 디자인 기준

## 프로필 예시

```markdown
# 프로필

- 이름: 홍길동
- 소속: 예시초등학교
- 학교급: 초등학교
- 직위: 교사
- 교과: 초등
- 연락처: 010-0000-0000
- 사무실: 032-000-0000
- 이메일: example@example.com
- 생년월일: 1990.01.01
- 주소: 예시 주소
- 최초 임용일: 2016.03.01
- 교원자격증: 예시번호
```
