# `(AI)` 작업공간과 외부 단건 파일

이 문서는 전국 선생님이 각자 다른 자료 구조를 가진 폴더를 쓰더라도 `teacher` skill이 안정적으로 동작하도록 만드는 기준이다. 배포용 skill에는 개인정보, 서명, 신분증, 통장사본, 증빙 파일, 완성 산출물을 넣지 않는다.

## 자동 적용 기준

- 사용자가 작업 대상 파일 또는 폴더 경로를 명시하면 현재 시작 폴더보다 그 대상 경로를 먼저 본다.
- 대상 경로 또는 상위 폴더 중 하나의 이름이 `(AI)`로 끝나면 대소문자를 구분하지 않고 가장 가까운 `(AI)` 폴더를 기준 작업폴더로 삼는다.
- 현재 폴더 또는 상위 폴더 중 하나의 이름이 `(AI)`로 끝나면 대소문자를 구분하지 않고 `teacher` 작업공간으로 본다.
- 예: `./양식(AI)/서명넣기/`와 `./양식(ai)/서명넣기/`에서 작업하면 둘 다 `양식(AI)` 작업공간 안의 하위 작업으로 처리한다.
- 사용자가 `$teacher`를 쓰지 않아도 이 skill의 workflow를 따른다.
- 사용자가 현재 작업공간 밖의 HWP/HWPX/XLS/XLSX/PDF/이미지 파일 경로를 직접 줬고 그 경로와 상위 폴더에 `(AI)` 작업공간이 없으면 외부 단건 파일로 처리한다.

## `(AI)` 작업공간 최초 세팅

1. 사용자가 명시한 작업 대상 경로가 있으면 그 경로와 상위 폴더를 먼저 확인하고, 없으면 현재 폴더와 상위 폴더 중 하나의 이름이 `(AI)`로 끝나는지 대소문자 구분 없이 확인한다.
2. 실행 환경별 에이전트 지시 파일을 만든다. Codex는 `AGENTS.md`, Claude는 `CLAUDE.md`를 사용한다. 공용 작업공간이거나 실행 환경이 불명확하면 둘 다 만들고 같은 teacher 지시문을 유지한다.
3. `docs/`가 없으면 만든다.
4. 원문을 열기 전에 폴더명, 파일명, 확장자만 읽어 1차 분류한다.
5. `docs/00_폴더지도.md`, `docs/01_분류기준.md`, `docs/02_자료목록.md`를 만든다.
6. 사용자의 현재 작업과 관련 있는 파일만 원문을 열어 추가 요약 Markdown을 만든다.

원본 파일을 새 폴더로 옮기거나 이름을 바꾸지 않는다. Markdown 문서에서만 분류와 연결 정보를 관리한다.

## 기본 `docs/` 구조

```text
docs/
├── 00_폴더지도.md
├── 01_분류기준.md
└── 02_자료목록.md
```

필요할 때만 작업 성격에 맞는 요약 문서를 추가한다.

```text
docs/이력서.md
docs/연수이수목록.md
docs/근무경력.md
docs/수업자료목록.md
docs/공문자료목록.md
docs/증빙목록.md
docs/양식목록.md
docs/발표자료목록.md
```

## 대분류 태그

파일 하나는 하나의 분류에만 속하지 않는다. `주분류` 하나와 `보조분류` 여러 개를 허용한다.

- 인사·이력·증빙: 이력서, 자기소개, 경력, 자격증, 연수 이수, 표창, 재직증명서, 통장사본, 신분증, 서명.
- 공적·성과·평가: 공적조서, 공적요약서, 표창, 연구대회, 수업실적, 업무성과, 성과보고, 교원평가.
- 공문·신청·보고: 신청서, 계획서, 결과보고서, 출장, 연수, 예산, 물품, 내부결재, 학교 업무 보고.
- 수업·교육과정: 수업지도안, 교수학습과정안, 차시 계획, 교육과정 재구성, 평가계획, 활동지, 학습지, 루브릭.
- 학급·생활교육: 학급운영, 상담, 생활지도, 학부모 안내, 학생 관찰, 출결, 안전교육, 학교폭력, 정서행동.
- 연수·강의·발표: 교원연수 자료, 강의안, 발표자료, 원고, 실습자료, 워크숍, HTML 슬라이드, PPT.
- 행사·프로젝트·동아리: 학교행사, 체험학습, 캠프, 동아리, 연구학교, 선도학교, AI/SW/디지털 프로젝트.
- 명단·집계·예산: 학생/교사 명단, 신청자 명단, 설문 결과, 통계, 예산서, 품의, 정산, 엑셀 집계표.
- 양식·템플릿: 빈 HWP/HWPX/XLSX/PPTX 양식, 반복 학교 서식, 기관 제출 서식.
- 디자인·미디어: 이미지, 사진, 로고, 서명, 도장, 캡처, PDF 참고자료, 발표 디자인 기준, 삽입용 미디어.

## `docs/00_폴더지도.md`

폴더 구조를 사람과 AI가 빠르게 볼 수 있게 요약한다. 원문 내용이 아니라 경로 구조와 추정 성격만 기록한다.

```markdown
# 폴더지도

| 폴더 | 주요 확장자 | 추정 성격 | 비고 |
|---|---|---|---|
| ./원본/양식 | hwp, hwpx, xlsx | 양식·템플릿; 공문·신청·보고 | 원문 미확인 |
| ./원본/수업 | hwpx, pdf, png | 수업·교육과정; 디자인·미디어 | 원문 미확인 |
```

## `docs/01_분류기준.md`

해당 프로젝트에서 실제로 쓰는 분류 기준과 예외를 기록한다. 기본 대분류를 복사하되, 프로젝트에 없는 분류는 생략해도 된다.

```markdown
# 분류기준

- 주분류: 해당 파일을 가장 먼저 찾을 업무 맥락.
- 보조분류: 같이 걸쳐 있는 업무 맥락. 세미콜론으로 여러 개를 기록한다.
- 원문 확인 상태: 미확인, 보류, 필요, 완료.
```

## `docs/02_자료목록.md`

파일 단위 인덱스다. 최초 세팅 때는 파일명, 폴더명, 확장자만으로 채우고 `원문 확인`은 대부분 `미확인` 또는 `보류`로 둔다.

```markdown
# 자료목록

| 주분류 | 보조분류 | 원본 폴더 | 파일명 | 확장자 | 추정 용도 | 원문 확인 | 요약 문서 | 비고 |
|---|---|---|---|---|---|---|---|---|
| 수업·교육과정 | 연수·강의·발표; 행사·프로젝트·동아리 | ./AI수업자료 | 공개수업 지도안.hwp | hwp | 수업지도안 참고 | 필요 | 미작성 | 파일명 기준 추정 |
| 공문·신청·보고 | 명단·집계·예산 | ./업무/예산 | 디지털교구 구입 계획.xlsx | xlsx | 예산/품의 자료 | 보류 | 미작성 | 파일명 기준 추정 |
```

## 원문 읽기 기준

- 최초 세팅 때 원문을 모두 열지 않는다.
- 사용자가 요청한 작업과 관련 있는 파일부터 연다.
- 원문을 열어 새로 확인한 내용은 기존 `docs/*.md`에 반영하거나 새 요약 문서를 만든다.
- `docs/`와 원본이 충돌하면 사용자의 최신 지시를 우선하고, 필요한 경우 Markdown의 출처와 갱신일을 갱신한다.

## 외부 단건 파일 처리

사용자가 현재 `(AI)` 작업공간 밖의 파일 경로를 직접 줬고 그 경로와 상위 폴더에도 `(AI)` 작업공간이 없으면 잠깐 쓰는 외부 단건 파일로 처리한다.

- 원본 파일을 덮어쓰지 않는다.
- `(AI)` 작업공간으로 복사하지 않는다.
- `docs/02_자료목록.md`에 기본 등록하지 않는다.
- 사용자가 명시적으로 기록해 달라고 한 경우에만 자료목록에 추가한다.
- 결과물은 원본 파일과 같은 폴더에 저장한다.
- 결과물 파일명은 원본 파일명 뒤에 `_완성본`을 붙인다.
- 같은 이름의 `_완성본` 파일이 이미 있으면 `_완성본2`, `_완성본3`처럼 번호를 붙인다.

예:

```text
원본:
./예시초등학교_출강수락_원고공개동의_강사초빙카드_홍길동.hwpx

결과:
./예시초등학교_출강수락_원고공개동의_강사초빙카드_홍길동_완성본.hwpx
```

## 최소 에이전트 지시 파일 템플릿

Codex 환경은 `AGENTS.md`, Claude 환경은 `CLAUDE.md`를 만든다. 공용 작업공간이거나 실행 환경이 불명확하면 두 파일을 모두 만들고 같은 내용을 넣는다.

````markdown
# 교사 업무문서 AI 작업공간

Codex는 `AGENTS.md`, Claude는 `CLAUDE.md`를 읽는다.
두 파일은 같은 작업 지침을 담도록 함께 유지한다.

작업 중 생성하거나 수정하는 모든 텍스트 파일은 UTF-8로 저장한다.
Python으로 파일을 읽거나 쓸 때는 `encoding="utf-8"`을 명시한다.
PowerShell에서 한국어 경로와 텍스트를 다룰 때는 먼저 아래를 실행한다.

```powershell
$OutputEncoding = [System.Text.Encoding]::UTF8
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
chcp 65001
```

이 폴더는 `teacher` skill workflow를 따른다.
먼저 `docs/`의 Markdown 자료를 읽고, 부족하거나 최신성이 의심될 때만 원본 파일을 연다.
최초 세팅 때는 원문을 모두 열지 말고 폴더명, 파일명, 확장자를 기준으로 폴더지도와 자료목록을 먼저 만든다.
````
